## 项目背景

智能体的提示词、工具、记忆和编排只有结合具体任务，才能观察它们之间的作用。Elsewhen 用七席隐藏身份议会提供一个有规则、有目标冲突、有局部信息的实验环境。用户与六个独立智能体共同参与，再从运行轨迹解释行为，或更换决策继续实验。

工具面向学习智能体工程的开发者、组织实践课的教师，以及验证多角色互动的设计者。浏览器提供完整操作入口；默认 Mock 模式无需模型密钥。当前定位是可运行的开源原型与仿真实验工具，尚不主张已验证的教学增益、规模化部署或真实模型优劣排名。

## 技术架构

- **交互层**：Next.js 16、React 19、Three.js，提供配置、议会、图执行、状态检查、复盘与批量实验页面；REST 提交操作，SSE 更新运行状态。
- **服务层**：FastAPI 负责会话入口与身份验证；LangGraph 负责阶段推进、人类输入中断、恢复与检查点。
- **智能体层**：每个席位有独立记忆线程、角色与获准上下文。已实现 Mock、OpenAI、Anthropic、Gemini、Ollama 及 Ollama Cloud 适配；真实模型需通过响应与工具调用预检查。
- **行动边界**：MCP 会话绑定席位身份，具体工具动作继续经过服务器的身份、阶段和目标验证。MCP 是工具接口，权限由应用实现。
- **证据层**：PostgreSQL 保存游戏、事件、工具提交、私人笔记、关系记忆及图检查点。回溯产生独立游戏与检查点线程，原记录不被覆盖。

席位权限、房主权限与运营历史访问权限分离；普通玩家只获得获准状态投影。观测界面呈现已记录的上下文、简短理由、工具行为与结果，不宣称暴露模型隐藏思维链。真实模型调用、图像生成和语音服务均需明确启用。

## 核心使用流程

1. 在首页选择“找到你的席位”，配置人类与 AI 席位，保留 `mock-v1` 即可离线演示。
2. 点击“测试模型并创建游戏”，再在议会页面点击“开始游戏”。
3. 按身份完成夜间行动、发言和投票；等待人类输入时图执行中断，提交合法行动后恢复。
4. 查看执行图；房主开启上帝视角后可检查独立席位上下文、历史检查点与状态差异。
5. 结束后打开 Learning debrief，查看运行证据、学习概念检查与技术轨迹。
6. 在 Branch replay 选择历史人类决策并替换目标，生成保留原记录的新分支。
7. 在 Model Tournament 配置七个 AI 席位、局数与预算，执行轮换角色的批量实验。

## 创新点与应用场景

| 能力 | 工具价值 | 典型场景 |
| --- | --- | --- |
| 可参与的多智能体环境 | 将信息不对称、目标冲突、人类输入放进同一任务链 | 智能体工程实践课、开发者培训 |
| 按席位观测证据 | 将公开说法、私有知识、记忆更新和合法动作区分开 | Agent 调试、上下文与权限检查 |
| 检查点分支实验 | 替换一个历史决策，保留原记录与当时的信息边界 | 策略探索、多角色交互原型验证 |
| 角色轮换批量实验 | 汇总行为、延迟与 Token 等指标，减少固定角色分配的偏差 | 模型接入验收、实验配置比较 |
| 无密钥的默认运行路径 | 评审、教学和贡献者可先复现完整工程流程 | 开源复用、持续回归验证 |

创新体现在以上能力的产品化组合与工程实现，不声称发明 LangGraph、MCP 或通用反事实算法。更换决策的分支对照不是严格因果证明；真实模型的随机性与版本变化仍需控制。

## 本次验证

2026-10-13，本地执行 `./check.sh`：后端 **99** 项测试通过；探索与资源测试 **15** 项通过；状态差异测试 **2** 项通过；ESLint、TypeScript 与 Next.js 生产构建通过。后端有一项 MCP 客户端接口弃用警告，不影响测试通过。

视频来自生产模式的真实浏览器操作，使用 `mock-v1`，未启用付费模型、AI 语音或图片服务。录制对局完成 2 回合、6 次人类操作、47 次 Mock 工具提交、61 个图执行步骤与 48 条持久化事件。改变第二回合投票后，分支进入第三回合；返回原对局仍显示第二回合村民获胜。

模型实验室另完成 7 局角色轮换实验，七席均为 `mock-v1`；汇总表中的 49 次 Games 指 7 席乘 7 局的席位样本。视频保留真实界面操作，剪去等待和部分重复回合，并使用本地合成普通话解说与中文字幕；解说不是游戏内付费语音服务。

Mock 数据用于演示流程和记录链路，不用于真实模型性能结论。界面中的估算 Token 不等于供应商实际账单。本次不验证外部模型账户、付费媒体服务或 Unreal 原生客户端。

## 开源与后续工作

项目采用 AGPL-3.0-only，保留依赖锁文件、启动脚本、测试、API/架构说明和第三方资源声明；[贡献指南](../../CONTRIBUTING.md) 规定复现、验证与审查要求。浏览器主应用不依赖 Unreal 或 Blender。Unreal 的 Android 开发文件服务在提交版本中关闭，模板中的令牌已清空。

拟按以下顺序推进：完善新手说明和中英文一致性；补充可版本化实验配置与真实模型复现实验；开展小规模课堂试用并定义学习效果指标；依据公开问题和社区贡献迭代维护。以上为计划，不作为已完成成果。
